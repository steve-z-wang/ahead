# Receipt before page

Initial authority: Entry.text = A at stamp 10. Local M1 writes B, M2 writes C; the visible text is C with A held as the before image. M1 is pushed alone and its receipt carries the authority the server read back after M1: Entry.text = B at stamp 11. The receipt completes M1 on arrival: B is staged under the still-pending M2 as the new base, M1's operation leaves the queue, and replay leaves the visible text C with B held. Nothing waits for the Book channel. When the channel page for cursor 11 later delivers the same record at stamp 11 with the same content, it rewrites nothing and only advances the cursor; a page at a lower stamp cannot regress the base. Repeat with the page arriving before the receipt (the base is already at stamp 11 when the receipt lands, so the receipt only clears M1) and with storage reopened at each durable boundary: the held base, the pending operation and the stamp evidence survive.
