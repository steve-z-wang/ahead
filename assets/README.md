# Assets

Shared visual assets for Ahead's README and other project surfaces.

## Branding

- [Horizontal logo](branding/ahead-logo.png) — transparent PNG used in the root README.
- [Standalone icon](branding/ahead-icon.png) — square transparent PNG with the A and three speed lines, without the wordmark.
- [Approved concept](branding/ahead-logo-concept.png) — original white-background reference for further iteration.

The mark combines a lightly rounded A, three speed lines on its right and the lowercase `ahead` wordmark. The intended brand color is vermilion red (`#E5392D`). These are raster drafts; a production vector master has not been created.

Generated with the built-in ImageGen tool. The transparent logo was derived from the approved concept using the prompt in [branding/imagegen-prompt.txt](branding/imagegen-prompt.txt).

The standalone icon was derived from the horizontal logo using [branding/icon-imagegen-prompt.txt](branding/icon-imagegen-prompt.txt).

See [Marketing](../marketing/README.md) for content plans and production work.
