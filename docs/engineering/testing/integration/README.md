# Integration tests

Verify a contract across a real boundary that a component fixture or simulation host cannot establish.

- [Storage and persistence](persistence.md) — SQLite and PostgreSQL transaction behavior.
- [SDKs and bindings](bindings.md) — Generated-language and native boundaries.
- [Connection](connection.md) — HTTP/WebSocket behavior.

The categories describe what a test establishes; related assertions may share a harness. Complete application flows belong in [End-to-end tests](../end-to-end.md).
